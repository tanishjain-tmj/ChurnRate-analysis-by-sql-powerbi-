# Customer Churn Analysis Using SQL and Power BI

## Project Overview

Customer retention is one of the most important factors for business growth and profitability. This project focuses on analyzing customer churn behavior using SQL for database management and Power BI for interactive data visualization. The objective is to identify patterns, trends, and factors that influence customer churn and provide actionable insights that can help businesses improve customer satisfaction and loyalty.

The project simulates a real-world business scenario by creating a customer dataset containing demographic information, subscription details, engagement metrics, feedback scores, and churn status. SQL is used for database creation, data storage, and analytical queries, while Power BI is utilized to transform raw data into meaningful dashboards and visual reports.

## Objectives

* Design and create a customer churn database using SQL.
* Import and manage customer data efficiently.
* Perform data analysis using SQL queries.
* Build interactive Power BI dashboards for visualization.
* Identify key factors contributing to customer churn.
* Generate business insights and recommendations for customer retention.

## Dataset Information

The dataset contains 500 customer records and includes the following attributes:

* Customer ID
* Customer Name
* Age
* Gender
* Subscription Type
* Join Date
* Total Sessions
* Feedback Score
* Days Since Last Activity
* Churn Status (Yes/No)

The dataset is designed to mimic real customer behavior and support churn analysis.

## SQL Implementation

The SQL component of the project includes:

* Database creation
* Table design and schema definition
* Data insertion using SQL scripts
* Data retrieval and filtering
* Aggregate analysis using SQL functions
* Churn-related analytical queries

Example analyses performed:

* Total customers
* Churn percentage
* Average feedback score
* Subscription-wise churn analysis
* Customer engagement statistics

## Power BI Dashboard Features

The Power BI dashboard provides an interactive visual representation of customer churn trends through:

* KPI Cards displaying:

  * Total Customers
  * Average Feedback Score
  * Churn Percentage
  * Average Days Since Last Activity

* Interactive Filters:

  * Subscription Type
  * Gender

* Visualizations:

  * Monthly Churn Trend Analysis
  * Churn Distribution Chart
  * Subscription-wise Churn Comparison
  * Customer Engagement vs Feedback Analysis

## Key Insights

1. Nearly half of the customers have churned, indicating a significant retention challenge.
2. Customer satisfaction levels are moderate, as reflected by the average feedback score.
3. Monthly subscription plans show higher churn compared to longer-term plans.
4. Customer churn peaks during specific months, suggesting seasonal trends.
5. Long-term customer engagement does not always guarantee higher satisfaction.
6. Subscription type plays an important role in customer retention.
